# Heritage Themes for Xcode Changelog

## [Unreleased]

## [1.5.0] - 2026-10-26

### Added

- Themes for Xcode, one for each Heritage theme, coloured from the theme's palette. Each comes as an `.xcworkspacecolortheme` for Xcode 27 and later, which colours the source editor and the toolbar, jump bar and status bar, and as an `.xccolortheme` for Xcode 26 and earlier, which colours the source editor, the console, the rendered documentation markup and the scroll bar markers and sets the editor font to SF Mono.
