## [Unreleased]

## [1.29.0] - 2026-11-28

### Added

- Themes for eza, one for each Heritage theme: a theme file that keeps the look of eza's default theme in the colours of the theme's palette, for file names by kind and type, permissions, sizes, users, links, dates, Git status, the header and punctuation. Folders take one of the family's syntax colours and dates another; plain files keep the terminal's colours.
