# Heritage Themes for yazi Changelog

## [Unreleased]

### Added

- Flavors for yazi, one for each Heritage theme: a flavor that colours file names and icons by kind, the hovered file, markers, find matches, modes, permissions, tabs, pop-ups and the help menu from the theme's palette, and a TextMate theme that colours the code preview. Folders, the mode, tabs and pop-up borders take a colour of the family's own; other files take the terminal colours of the matching terminal theme.
- The flavors install with yazi's package manager from heritage-themes/yazi-flavors: `ya pkg add heritage-themes/yazi-flavors:<flavor>`.
