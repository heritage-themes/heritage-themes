# Heritage Themes for Neovim Changelog

## [Unreleased]

### Added

- Colour schemes for Neovim, one for each Heritage theme. They colour the editor, Tree-sitter captures, LSP semantic tokens, diagnostics, the status line, tab line, floating windows, the completion menu, diff mode and the terminal from the theme's palette.
- A lualine theme for each colour scheme, under the same name, and colours for the signs of gitsigns.nvim.
