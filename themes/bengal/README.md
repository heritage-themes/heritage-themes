# Bengal

Dark and light themes based on the colours of Bengal: the silk and cotton of its looms and the colours of Durga Puja (দুর্গাপূজা). Provides two UI themes, **Bengal Baluchari** and **Bengal Laal Paar**, each with a matching editor colour scheme.

![Preview](preview.png)

## Inspiration

Each syntax role takes one colour of the region:

| Colour | Source | Role |
| --- | --- | --- |
| Aparajita (অপরাজিতা) | Butterfly-pea flower violet-blue | Keywords |
| Baluchari magenta | Figured silk of Bishnupur | Strings |
| Paddy green | Rice fields | Methods |
| Terracotta | Temple brick of Bishnupur | Types |
| Sorshe (সর্ষে) | Mustard flower | Fields |
| Sindoor (সিঁদুর) | Vermilion powder worn in the hair parting | Numbers |
| Pond teal | Village ponds (pukur) | Constants |
| Neel (নীল) | Indigo dye of Bengal | Annotations |
| Mangrove green | Sundarbans | Type parameters |
| Shankha (শাঁখা) | Conch-shell bangle white | Text on Baluchari |
| Shiuli (শিউলি) stem | Orange stem of the night jasmine | Caret on Baluchari |
| Pola (পলা) | Coral bangle red, worn with the shankha | Spock labels |

Bengal Baluchari is the deep wine silk of Bishnupur, woven with figured borders (বালুচরী). Bengal Laal Paar is the white cotton sari with a red border (লাল পাড়), worn for the Puja and sindoor khela. Hex values are interpretations of the traditional colours, adjusted for contrast against each background.

## Develop

The palettes are in `theme.py`. The colour mappings and the preview are shared by every theme family and live in [`heritage/`](../../heritage/). See the [root README](../../README.md) for build, preview and install steps.
