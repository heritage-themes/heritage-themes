# Heritage Themes for NetBeans Changelog

## [Unreleased]

## [1.24.0] - 2026-11-24

### Fixed

- Code and text keep WCAG AA contrast on the theme's green and red highlight backgrounds, as on code coverage, breakpoint lines and the remove surround code preview. In 44 themes those backgrounds are a shade lighter in light themes or darker in dark ones, with their hue and depth of colour kept.

## [1.14.0] - 2026-11-21

### Added

- A NetBeans plugin with a look and feel and an editor colour profile for each Heritage theme. The look and feel colours NetBeans' windows, menus, dialogs and tabs; the profile colours the editor in Java and every other language that NetBeans colours, with the selection, the current line, matching braces, found text, line numbers, breakpoints and the debugger's lines.
