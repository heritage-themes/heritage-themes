## [1.7.0] - 2026-11-05

### Added

- Colour schemes for Nano, one for each Heritage theme. They colour the title bar, mini bar, status bar, error messages, prompts, the selection, search matches, the guide stripe, the scroll indicator, line numbers and the help lines from the theme's palette; code takes the palette's ANSI colours from the matching terminal theme.
