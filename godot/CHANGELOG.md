# Heritage Themes for Godot Changelog

## [Unreleased]

### Fixed

- Code and text keep WCAG AA contrast on the theme's green and red highlight backgrounds, as on the lines that the script editor marks with an error. In 44 themes those backgrounds are a shade lighter in light themes or darker in dark ones, with their hue and depth of colour kept.

## [1.13.0] - 2026-11-20

### Added

- A plugin for the Godot editor that applies a Heritage theme from **Project | Tools | Heritage Themes...**: a text editor theme for each Heritage theme, which colours the script editor, and the base colour, accent colour and contrast that Godot draws the rest of the editor from.
