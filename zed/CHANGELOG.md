# Heritage Themes for Zed Changelog

## [Unreleased]

### Fixed

- Code keeps WCAG AA contrast on the current line's highlight. In 33 themes, the code colours that fell just below 4.5:1 on it are a shade darker in light themes or lighter in dark ones.
- The current line's number in Kerala Kasavu (Light) reaches 4.5:1.

## [1.3.2] - 2026-10-23

### Changed

- The extension ID is `heritage-theme`, which marks it as a theme extension for Zed's extension registry.

## [1.3.1] - 2026-10-23

### Added

- Themes for Zed, one for each Heritage theme. They colour the editor, panels, tabs, title and status bars, terminal and popups from the theme's palette.
