# Heritage Themes for GNOME Text Editor Changelog

## [Unreleased]

### Fixed

- Code and text keep WCAG AA contrast on the theme's green and red highlight backgrounds, as on the outline's labels and GNOME Builder's count points. In 44 themes those backgrounds are a shade lighter in light themes or darker in dark ones, with their hue and depth of colour kept.

## [1.18.0] - 2026-11-22

### Added

- GNOME Builder support: each scheme colours Builder's diagnostics, breakpoints, changed lines in the gutter, other occurrences of the selected text, the matching XML tag, the link to a definition under the pointer and the labels in the outline of XML files. Without these styles, Builder drew errors, warnings and notes in the colours of the code's own error, warning and comment-alert styles.

## [1.17.0] - 2026-11-22

### Added

- A style scheme for each Heritage theme, which colours the editor and GNOME Text Editor's window. A family's dark and light schemes are a pair, so the editor switches between them with the desktop's style.
