# Heritage Themes for RStudio Changelog

## [Unreleased]

### Added

- Editor themes for RStudio, one for each Heritage theme. They colour the source editor, the console, the Terminal tab and the visual editor of R Markdown and Quarto documents: code, the selection, the current line, matching brackets, found text, code chunks, line numbers, the caret, the line that the debugger stops on and the colours of the terminal.
