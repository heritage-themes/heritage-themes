# Heritage Themes for Spyder Changelog

## [Unreleased]

## [1.9.1] - 2026-11-12

### Added

- Syntax highlighting themes for Spyder 6, one for each Heritage theme, and an installer that adds them to `spyder.ini`. They colour the editor and the IPython console: code, the current line and cell, occurrences, bracket matches, links and the side areas.
