# Heritage Themes for fzf Changelog

## [Unreleased]

### Added

- Themes for fzf, one for each Heritage theme: an options file that colours the matched characters, the current line and the gutter, the prompt, the pointer and the spinner, the marker of selected lines, the match counters, the header, borders, the separator and the scroll bar from the theme's palette. The matched characters take one of the family's syntax colours and the prompt and the pointer another; text keeps the terminal's colours.
