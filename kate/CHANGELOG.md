# Heritage Themes for Kate Changelog

## [Unreleased]

### Fixed

- The terminal colours keep WCAG AA contrast on the selection, in focused and unfocused views. In 40 themes the red, green, yellow, blue, magenta or cyan that fell short is a shade lighter in dark themes or darker in light ones, with its hue kept.

## [1.24.0] - 2026-11-24

### Fixed

- Code and text keep WCAG AA contrast on the theme's green and red highlight backgrounds, as on replaced text and template placeholders. In 44 themes those backgrounds are a shade lighter in light themes or darker in dark ones, with their hue and depth of colour kept.

## [1.17.0] - 2026-11-22

### Changed

- The README gives KWrite's menu and Flathub data folder beside Kate's.

## [1.16.0] - 2026-11-22

### Added

- A colour theme and a window colour scheme for each Heritage theme, for Kate and other apps built on KTextEditor. Choosing the window colour scheme also chooses the theme of the same name while Kate follows the system colour scheme.
