# Heritage Themes for Notepad++ Changelog

## [Unreleased]

### Fixed

- Preprocessor directives, such as C and C++ `#include` and `#define`, no longer take the keyword colour. They take a colour of their own, which also stands apart from macros and comments. Assembler directives keep the keyword colour.

## [1.7.3] - 2026-11-05

### Changed

- No change to the themes beyond 1.7.0, which was not published. This version publishes them.

### Changed

## [1.7.0] - 2026-11-05

### Fixed

- Code keeps WCAG AA contrast on the current line's highlight. In 33 themes, the code colours that fell just below 4.5:1 on it are a shade darker in light themes or lighter in dark ones.
- The current line's number in Kerala Kasavu (Light) reaches 4.5:1.

## [1.4.0] - 2026-10-24

### Added

- Themes for Notepad++, one for each Heritage theme. They colour every language that Notepad++ highlights, the caret, current line, selection, margins, fold markers, highlights, the document map and the bar of the active tab from the theme's palette, and in Light Mode the tabs' text.
