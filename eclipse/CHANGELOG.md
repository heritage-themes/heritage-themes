# Heritage Themes for Eclipse Changelog

## [Unreleased]

### Changed

- No change to the themes beyond 1.7.0, which was not published. This version publishes them.

## [1.7.0] - 2026-11-05

### Added

- Themes for Eclipse, one for each Heritage theme, in one plugin. They colour the window, views, tabs, forms and the status line, and the editors, Java with JDT's semantic highlighting, Ant, the console, EGit, compare, Mylyn and EclEmma from the theme's palette, with a TextMate theme of the same name for the languages that TM4E highlights.
