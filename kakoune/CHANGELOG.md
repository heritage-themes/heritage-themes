# Heritage Themes for Kakoune Changelog

## [Unreleased]

### Changed

- No change to the themes beyond 1.7.0, which was not published. This version publishes them.

## [1.7.0] - 2026-11-05

### Fixed

- In 33 themes, some code colours are a shade darker in light themes or lighter in dark ones, matching the Heritage themes for other editors, which keep WCAG AA contrast on the current line's highlight.
- The current line's number in Kerala Kasavu (Light) reaches 4.5:1.

## [1.6.0] - 2026-11-03

### Added

- Colour schemes for Kakoune, one for each Heritage theme. They colour the editor, selections, cursors, line numbers, menus, information boxes, diagnostics, the status line and the prompt from the theme's palette.
