# Heritage Themes for Helix Changelog

## [Unreleased]

## [1.11.1] - 2026-11-14

### Fixed

- Preprocessor directives, such as C and C++ `#include` and `#define`, no longer take the keyword colour. They take a colour of their own, which also stands apart from comments.

## [1.7.3] - 2026-11-05

## [1.7.0] - 2026-11-05

### Fixed

- Code keeps WCAG AA contrast on the current line's highlight. In 33 themes, the code colours that fell just below 4.5:1 on it are a shade darker in light themes or lighter in dark ones.
- The current line's number in Kerala Kasavu (Light) reaches 4.5:1.

## [1.6.0] - 2026-11-03

### Added

- Themes for Helix, one for each Heritage theme. They colour the editor, the gutter, cursors, selections, diagnostics, the status line, buffer line, pickers, popups, the completion menu, inlay hints and jump labels from the theme's palette.
