# Heritage Themes for Sublime Text Changelog

## [Unreleased]

### Fixed

- Code keeps WCAG AA contrast on the current line's highlight. In 33 themes, the code colours that fell just below 4.5:1 on it are a shade darker in light themes or lighter in dark ones.
- The current line's number in Kerala Kasavu (Light) reaches 4.5:1.

## [1.3.0] - 2026-10-22

### Added

- Colour schemes for Sublime Text, one for each Heritage theme.
- A UI theme for each colour scheme, under the same name. It extends the built-in Adaptive theme and colours the sidebar, tabs, panels, status bar and popups from the scheme's palette.
