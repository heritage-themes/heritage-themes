## [1.3.0] - 2026-10-22

### Added

- Colour schemes for Sublime Text, one for each Heritage theme.
- A UI theme for each colour scheme, under the same name. It extends the built-in Adaptive theme and colours the sidebar, tabs, panels, status bar and popups from the scheme's palette.
