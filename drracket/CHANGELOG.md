# Heritage Themes for DrRacket Changelog

## [Unreleased]

### Added

- Colour schemes for DrRacket, one for each Heritage theme, in the Racket package `heritage-themes`. They colour the definitions and interactions windows: code, line numbers, matching parentheses, the REPL's values, output and errors, error highlights, Check Syntax's identifiers, arrows and highlights, test coverage and the stepper.
