# Heritage Themes for Micro Changelog

## [Unreleased]

## [1.7.1] - 2026-11-05

### Changed

- No change to the themes beyond 1.7.0, which was not published. This version publishes them.

## [1.7.0] - 2026-11-05

### Fixed

- Code keeps WCAG AA contrast on the current line's highlight. In 33 themes, the code colours that fell just below 4.5:1 on it are a shade darker in light themes or lighter in dark ones.
- The current line's number in Kerala Kasavu (Light) reaches 4.5:1.

## [1.6.0] - 2026-11-03

### Added

- Colour schemes for Micro, one for each Heritage theme. They colour the editor, selections, line numbers, the cursor line, search matches, the gutter's marks, the status line, the tab bar, split dividers and the completion menu from the theme's palette.
