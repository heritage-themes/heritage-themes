# Heritage Themes for IDLE Changelog

## [Unreleased]

### Fixed

- The terminal colours keep WCAG AA contrast on the selection, in focused and unfocused views. In 40 themes the red, green, yellow, blue, magenta or cyan that fell short is a shade lighter in dark themes or darker in light ones, with its hue kept.

## [1.11.0] - 2026-11-12

### Added

- Highlighting themes for IDLE, one for each Heritage theme, and an installer that adds them to `config-highlight.cfg`. They colour the editor, the shell and the code context: code, the selection, found text, breakpoints, syntax errors, line numbers, the cursor, the prompt and the shell's output.
